주식 단타매매 자동화 프로젝트
검토 및 개발계획

1. 프로젝트 개요 및 폴더 구조

  • 목적: 주식 단타매매 자동화 프로그램 (AI 기반 데이터 수집, 분석, 예측, 자동주문, 리포트)
  • 주요 폴더/파일:
    • src/ : 핵심 소스코드 (데이터, 모델, 백테스팅, 트레이딩, 리포트 등)
    • main.py : 전체 파이프라인 실행(데이터→학습→예측→리포트)
    • gui_app.py : PyQt6 기반 GUI 대시보드
    • requirements.txt : 의존성 관리
    • tests/ : 단위/통합 테스트
    • models/, results/, data/ : 모델, 결과, 데이터 저장
    • docs/MVP_PLAN.md, ISSUES.md/json : 개발 계획, 이슈, 아키텍처 문서

3. 개발 로드맵

[1단계] 데이터/환경 구축
- 가상환경, requirements.txt, 기본 폴더 구조
- 증권사 API 연동(모의계정, 인증키 관리)
- 데이터 수집/저장(시세, 펀더멘탈, 매크로)
[2단계] 데이터 처리/모델링
- 전처리, 피처 엔지니어링, 통합 데이터셋 구축
- ML 모델(랜덤포레스트 등) 학습/저장
- 예측/신호 생성, 리포트 자동화
[3단계] 전략/백테스팅/자동매매 (진행중)
- 단타 전략(이동평균, RSI 등) 구현
- 백테스트 프레임워크(수익률, 리스크, 거래비용 반영)
- 실전 자동매매(주문 API, 실시간 모니터링, 예외처리)
[4단계] GUI/운영 자동화
- PyQt6 GUI 대시보드: 실시간 실행, 로그, 리포트, 설정 등 시각화 구현 완료
- 스케줄러/자동화: run_auto_pipeline.py, 작업스케줄러/cron 자동화, 장애 복구/재시작/로그/알림 자동화 완료
- 텔레그램/디스코드/이메일 알림, 실시간 모니터링: 주문/체결/잔고/장애/리포트 실시간 알림 및 모니터링 구현 완료
- (이메일 알림, 실시간 파라미터 조정 등 추가 확장 가능)
[5단계] 고도화/실전 적용
- 전략 다변화(딥러닝, 강화학습, 멀티모델)
- 실전 계좌 연동, 자금관리, 위험관리
- 실시간 데이터/주문, 장애 복구, 운영 자동화

4. 실전 운영/고도화/보안 업그레이드 현황

  • 실계좌 실매매(주문/체결/잔고) 실전 적용
    - 실계좌 환경에서 실전 주문/체결/잔고 모듈을 실제 API로 검증
    - 장애 복구, 실시간 모니터링, 텔레그램/디스코드/이메일 알림 연동
    - 민감정보(키/시크릿/토큰) 환경변수 관리, 로그/print 마스킹 적용
  • 실시간 리포트 자동 생성 및 디스코드/이메일 전송
    - 자동 리포트 생성, 디스코드/이메일 API 연동, 실시간 결과/장애/성과 리포트 전송
    - src/reporting/create_report.py, src/trading/discord_notify.py 등 구현
  • 운영 자동화(윈도우 작업스케줄러/cron)
    - run_auto_pipeline.py, 작업스케줄러/cron 등록, 장애 복구/재시작/로그 자동화, 운영자 알림
  • 신규 전략(모멘텀, AI 등) 추가 및 통합 검증
    - 모멘텀, AI 기반 등 신규 전략 알고리즘 구현, 기존 파이프라인에 통합, end-to-end 테스트
    - src/modeling/strategy_signals.py 등
  • 운영 보안 점검 및 개선
    - API키/비밀번호/환경변수 노출 방지, 로그 민감정보 마스킹, 외부 통신 HTTPS 암호화
    - 의존성 취약점 점검, 인증/인가/권한 최소화, 예외처리 강화
    - 운영환경 secret manager/vault 사용 권장, pip-audit 등 도구 적용
